# homebrew-naked

Homebrew tap for [naked](https://naked-cli.cc) — an SSH terminal that reattaches to your tmux session the moment the link comes back.

```sh
brew install axelbaumlisto/naked/naked
```

Current version: **0.1.0-beta.2** (Apple silicon, macOS 12+; signed with Developer ID and notarized).
Update with `brew upgrade naked`. Release files: https://github.com/axelbaumlisto/naked/releases
